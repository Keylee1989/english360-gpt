# PHASE 3A — 360-Day English Learning System Blueprint

**Date**: August 21, 2026
**Status**: DESIGN DOCUMENT (No Coding)
**Target**: Chinese native beginner → Functional English in 12 months

---

## Executive Summary

This document designs a complete 360-day English learning curriculum and system architecture for a Chinese native speaker starting from zero English knowledge. The system combines structured curriculum (Duolingo-style), spaced repetition (Anki-style), adaptive coaching (tutor-style), and speaking/listening training.

**Key Design Principles:**
1. Learning effectiveness over gamification
2. Real-world communication ability
3. Long-term retention via SRS
4. Practical implementation feasibility
5. 4 hours/day study commitment

## Task 1 — 360-Day Curriculum Structure

### Overview

The curriculum is divided into 5 stages, each building upon the previous:

```
Stage 1: Foundation (Day 1-30)      → Survival English
Stage 2: Basic Communication (Day 31-90)  → Daily Conversations
Stage 3: Intermediate (Day 91-180)   → Real Conversations
Stage 4: Practical American (Day 181-270) → Work & Life
Stage 5: Fluency (Day 271-360)       → Natural Communication
```

### Stage 1: Foundation (Day 1-30)

**Goal:** Build pronunciation foundation, basic survival English, 500-800 high-frequency words, basic sentence patterns.

**Target Vocabulary:** 500-800 words (A1 level)
**Target Grammar:** 15-20 basic patterns
**Target Listening:** Understand slow, clear speech
**Target Speaking:** Basic greetings, self-introduction, numbers, time

#### Week 1 (Day 1-7): Phonics & Greetings
- **Phonics:** Alphabet A-Z, short vowels, consonants
- **Vocabulary:** 50 words (greetings, numbers 1-20, colors, family)
- **Grammar:** "I am...", "This is...", "I have..."
- **Listening:** Isolated sounds, slow single words
- **Speaking:** Hello, goodbye, self-introduction, numbers

#### Week 2 (Day 8-14): Basic Verbs & Objects
- **Phonics:** Long vowels, common digraphs (sh, ch, th)
- **Vocabulary:** 80 words (common nouns, basic verbs, adjectives)
- **Grammar:** Present simple, "I want...", "I like..."
- **Listening:** Single words, short phrases
- **Speaking:** Requesting, describing objects, asking "what?"

#### Week 3 (Day 15-21): Daily Expressions
- **Phonics:** Blends, r-controlled vowels
- **Vocabulary:** 100 words (food, body parts, clothing, home)
- **Grammar:** "There is/are...", prepositions, articles
- **Listening:** Short sentences, slow speed
- **Speaking:** Ordering food, asking directions, describing surroundings

#### Week 4 (Day 22-30): Consolidation
- **Phonics:** Review all patterns, multisyllabic words
- **Vocabulary:** 120 words (time, weather, basic adjectives)
- **Grammar:** Review all patterns, simple questions
- **Listening:** Connected speech at slow speed
- **Speaking:** Extended self-introduction, simple conversations

**Milestone Assessment Day 30:**
- Vocabulary test: 500+ words recognized
- Pronunciation: Can produce all English sounds
- Listening: Understand simple sentences at slow speed
- Speaking: 2-minute self-introduction, basic Q&A

### Detailed Daily Schedule

#### Example: Day 45 (Stage 2)

**Hour 1: Vocabulary & SRS (60 minutes)**
- 0-15 min: SRS review of due cards (20-30 cards)
- 15-35 min: Learn 10 new words with examples
- 35-50 min: Practice exercises (recognition, recall, typing)
- 50-60 min: Review difficult words

**Hour 2: Listening Training (60 minutes)**
- 0-15 min: Listen to slow dialogue (3x times)
- 15-30 min: Comprehension questions
- 30-45 min: Listen and repeat (shadowing)
- 45-60 min: Listen at normal speed

**Hour 3: Grammar & Reading (60 minutes)**
- 0-20 min: Grammar explanation + examples
- 20-40 min: Grammar exercises
- 40-60 min: Read simple article, answer questions

**Hour 4: Speaking Practice (60 minutes)**
- 0-15 min: Pronunciation practice (difficult sounds)
- 15-35 min: Conversation simulation (AI or recording)
- 35-50 min: Free speaking (describe pictures, tell story)
- 50-60 min: Review and note mistakes

  // Adaptation State
  adaptation: {

  };

#### Adaptation Rules

```typescript
interface AdaptationRule {
  condition: (profile: LearnerProfile) => boolean;
  action: (profile: LearnerProfile) => LearnerProfile;
  priority: number;
}

// Example Rules:
const rules: AdaptationRule[] = [
  {
    // If listening is weak, increase listening tasks
    condition: (p) => p.skills.listening < p.skills.reading - 15,
    action: (p) => ({
      ...p,
      adaptation: {
        ...p.adaptation,
        exerciseTypeWeights: {
          ...p.adaptation.exerciseTypeWeights,
          listening_choice: p.adaptation.exerciseTypeWeights.listening_choice + 0.2,
        }
      }
    }),
    priority: 1
  },
  {
    // If accuracy is low, reduce difficulty
    condition: (p) => p.metrics.accuracy < 0.6,
    action: (p) => ({
      ...p,
      adaptation: {
        ...p.adaptation,
        currentDifficulty: Math.max(0, p.adaptation.currentDifficulty - 0.1)
      }
    }),
    priority: 2
  },
  {
    // If learning fast, increase new content
    condition: (p) => p.metrics.learningSpeed > 15, // >15 words/hour
    action: (p) => ({
      ...p,
      adaptation: {
        ...p.adaptation,
        newContentRatio: Math.min(0.8, p.adaptation.newContentRatio + 0.1)
      }
    }),
    priority: 3
  },
  {
    // If forgetting rate high, increase reviews
    condition: (p) => p.metrics.forgettingRate > 0.3,
    action: (p) => ({
      ...p,
      adaptation: {
        ...p.adaptation,
        reviewFrequency: Math.min(2.0, p.adaptation.reviewFrequency + 0.2)
      }
    }),
    priority: 4
  }
];
```

#### Difficulty Adjustment

```typescript
function calculateDifficulty(profile: LearnerProfile): number {
  let difficulty = 0.5; // Base
  
  // Adjust based on accuracy
  if (profile.metrics.accuracy > 0.85) difficulty += 0.1;
  if (profile.metrics.accuracy < 0.65) difficulty -= 0.1;
  
  // Adjust based on learning speed
  if (profile.metrics.learningSpeed > 12) difficulty += 0.05;
  if (profile.metrics.learningSpeed < 6) difficulty -= 0.05;
  
  // Adjust based on streak
  if (profile.metrics.streakDays > 7) difficulty += 0.05;
  
  // Clamp
  return Math.max(0.1, Math.min(0.9, difficulty));
}
```

#### Daily Workload Adjustment

```typescript
function calculateDailyWorkload(
  profile: LearnerProfile,
  targetMinutes: number
): DailyWorkload {
  const reviewRatio = 0.3 + (profile.metrics.forgettingRate * 0.2);
  const newContentRatio = 1 - reviewRatio;
  
  // Calculate items based on time
  const reviewItems = Math.floor(targetMinutes * reviewRatio / 2); // 2 min per item
  const newItems = Math.floor(targetMinutes * newContentRatio / 5); // 5 min per new word
  
  return {
    reviewCount: reviewItems,
    newWordCount: newItems,
    exerciseCount: Math.floor(targetMinutes / 3), // 3 min per exercise
    speakingMinutes: Math.floor(targetMinutes * 0.25),
    listeningMinutes: Math.floor(targetMinutes * 0.25),
  };
}
```

## Task 8 — Assessment System

### Entry Assessment

**Purpose:** Determine starting level and create personalized plan.

**Components:**
1. **Self-assessment questionnaire** (Chinese)
2. **Vocabulary recognition test** (50 words, multiple choice)
3. **Listening comprehension** (5 simple sentences)
4. **Pronunciation check** (repeat 10 sounds)

**Output:**
- Starting level: 0-5 (0=zero, 5=advanced)
- Recommended stage: 1-5
- Estimated timeline
- Personalized settings

### Monthly Assessments

**Frequency:** Every 30 days

**Components:**
1. **Vocabulary test** (100 words, mixed types)
2. **Grammar test** (20 questions)
3. **Listening test** (3 passages, 10 questions)
4. **Speaking test** (2-minute recording)
5. **Reading test** (1 passage, 10 questions)
6. **Writing test** (1 short paragraph)

**Output:**
- Skill scores (0-100)
- Progress compared to previous month
- Strengths and weaknesses
- Recommendations for next month

### Milestone Assessments

#### Day 30 Milestone
**Expected Achievements:**
- Recognize 500+ words
- Produce all English sounds
