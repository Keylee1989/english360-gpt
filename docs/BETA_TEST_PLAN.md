# English360 Beta Test Plan

## Overview

This document outlines the plan for beta testing English360 with real Chinese beginners.

- **Age**: 20-50 years old
- **Nationality**: Chinese native speakers
- **English Level**: Zero to elementary
- **Device**: iPhone users (iOS Safari)

| Skill | Target | Measurement |
|-------|--------|-------------|
| Vocabulary | 300 words | Recognition + Recall |
| Listening | 60%+ | Comprehension tests |
| Speaking | Self-introduction | 3-minute recording |
| Reading | Simple articles | Comprehension questions |
| Writing | 5-10 sentences | Daily diary |

## Success Criteria

### Primary Goals
1. **Completion Rate**: >70% of users complete 30 days
2. **Daily Retention**: >50% of users study daily
3. **Vocabulary**: Average 250+ words learned
4. **Satisfaction**: Average rating >3.5/5

### Secondary Goals
1. **Speaking**: 80%+ can introduce themselves
2. **Listening**: 70%+ understand slow conversations
3. **Recommendation**: 70%+ would recommend to friends
